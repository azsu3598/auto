# Notion에서 사부의 차트 교재 읽기

교재는 통합 Markdown 한 파일과 장별 Markdown 묶음 두 형태로 제공한다.
휴대전화에서는 장별 페이지로 읽는 방식을 권한다. 둘은 같은 본문을 사용하므로
처음에는 한 방식만 가져오면 중복 페이지가 생기지 않는다.

## 데스크톱에서 가져오기

한 페이지로 읽으려면 Notion 데스크톱 또는 웹에서 설정 → 가져오기 → Text &
Markdown을 열고 사부의_차트_교재_통합본.md를 선택한다.

장별로 읽으려면 Notion의 가져오기에서 ZIP을 페이지로 변환하는 항목을 찾아
Notion_장별_가져오기.zip을 선택한다. 지원되는 경우 페이지에서 /zip으로도
시작할 수 있다. 항목 이름은 앱 언어·버전·계정에 따라 다르게 보일 수 있다.

ZIP 가져오기가 보이지 않거나 실패하면 압축을 풀고 장별 폴더의 Markdown 파일을
Text & Markdown으로 여러 개 선택해 가져온다. 교재_목차.md와
휴대전화_매매전_체크리스트.md도 함께 가져올 수 있다.

첫 단계에서 임의의 한 장만 먼저 가져와 한글·제목·코드 블록을 확인하는 것도 좋다.
전체를 다시 시도하기 전 부분적으로 만들어진 페이지가 있는지 확인한다.

## 휴대전화에서 읽기

가져오기는 데스크톱이나 웹에서 하고, 같은 계정·워크스페이스로 모바일 앱을 연다.
동기화된 교재 페이지를 찾아 즐겨찾기에 추가하면 다시 찾기 쉽다. 가져오기 기능은
확인 기준일의 공식 안내상 모바일에서 지원되지 않는다.

한 장씩 읽고 문제에 먼저 답한 뒤 해설을 본다. 21장의 학습 노트는 별도 연습 페이지에
복사해 사용한다. 계좌번호·API 키·비밀번호·토큰은 학습 노트에 넣지 않는다.

## 목차와 링크 확인

파일 목차와 이전·다음 링크는 로컬 Markdown 파일 사이의 상대 링크다. Notion이
가져온 페이지 링크로 바꾸지 못했다면 그대로 동작한다고 가정하지 않는다.
가져온 장별 페이지를 교재 목차 아래로 모으고 Notion의 페이지 링크로 다시 연결한다.
00~23 숫자가 있어 순서를 확인할 수 있다.

Notion은 Markdown의 앵커 링크와 일부 확장 문법을 그대로 가져오지 않을 수 있다.
통합본에는 직접 만든 앵커 링크를 사용하지 않았다. 필요하면 가져온 페이지에서
Notion 기본 목차 블록을 추가한다. 이 교재는 복잡한 표·HTML·외부 그림에 의존하지 않는다.

단순히 파일을 Notion으로 열어 읽기 전용 미리보기를 보는 것과 워크스페이스에
가져오는 것은 다르다. 휴대전화에서 계속 읽고 메모하려면 가져온 페이지가 원하는
워크스페이스에 저장됐는지 확인한다.

## 확인할 내용

- [ ] 장별 본문 24개가 00~23 순서로 보인다.
- [ ] 양봉 개념도와 세 매수 자리의 짧은 도식이 읽힌다.
- [ ] 12장의 수량 계산과 17장의 가상 사례가 중간에 잘리지 않았다.
- [ ] 20장의 훈련표와 21장의 노트가 편집 가능한 내용으로 들어왔다.
- [ ] 출처 링크가 열리고 통합본과 장별 본문을 중복 수입하지 않았다.

책 파일과 ZIP의 UTF-8·본문 일치·내부 링크·압축 무결성은 제작 시 검사한다.
실제 Notion 가져오기 결과와 기기별 화면 배치는 사용자가 가져온 뒤 확인해야 한다.
