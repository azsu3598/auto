## 기존 참고자료 읽는 순서

토스 차트 설정 자료는 예전 앱 사용에 관한 참고용이다. 현재 자동매매 연동 대상은
키움증권이며 새 학습의 기본 순서는 위 정규 교재를 따른다.

1. `토스증권_차트설정_실전가이드.md`
   - 토스에서 일봉·5분봉·이동평균선·거래량을 표시하는 방법
2. `차트쟁이_모바일_전술수첩.md`
   - 장중에 휴대전화로 빠르게 확인하는 체크리스트
3. `은퇴한_차트쟁이의_시야와_매매전술.md`
   - 시장부터 손절까지 이어지는 전체 매매 사고방식

## 기본 학습 순서

```text
시장 상태
→ 거래대금과 주도 업종
→ 뉴스와 가격 반응
→ 일봉 위치
→ 5분봉 20이평과 거래량
→ 진입 조건
→ 무효화·손절 조건
```

## 반드시 기억할 원칙

- 차트는 미래를 확정하는 도구가 아니라 현재 매수·매도 주도권을 확인하는 도구다.
- 좋은 뉴스와 좋은 매수 자리는 다르다.
- 일봉으로 종목과 위치를 고르고 5분봉으로 진입 시점을 판단한다.
- 5분봉 20이평은 최근 5분봉 20개의 종가 평균이며, 대략 최근 100분의 평균 가격대다.
- 이동평균선 하나만으로 주문하지 않는다. 가격 위치·방향·거래량·시장 상태를 함께 본다.
- 조건이 불분명하면 현금 보유도 올바른 매매 판단이다.
