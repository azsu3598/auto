# 종가베팅 기록 작성 및 분석 지침

## 목적
이 파일은 다른 ChatGPT 세션에서 기존 종가베팅 실험을 그대로 이어가기 위한 인수인계 지침이다.
핵심 목표는 수익 극대화가 아니라 **저품질 거래를 피하고 손실을 통제하는 것**이다.
조건이 약하거나 데이터가 불충분하면 `NO_TRADE`가 정상적인 결론이다.

---

## 1. 함께 제공되는 기준 파일

- 거래기록 현재본: `종가베팅_거래기록_현재본.xlsx`
- 일일 기록 현재본: `종가베팅_일일기록_현재본.md`
- 2026-08-10 보존본: `종가베팅_20260810_A_B_테스트기록.md`
- 2026-08-11 거래기록 보존본: `종가베팅_거래기록_20260811_NO_TRADE반영.xlsx`

기존 기록은 삭제하거나 임의 수정하지 말고, 새 거래일은 기존 형식을 이어서 추가한다.

## 2. 현재 실험 상태

### 공통 1회차: 2026-08-06 매수 → 2026-08-07 매도
- 시작자산: 600,000원
- 손익: -9,440원
- 계좌수익률: -1.57%
- 종료자산: 590,560원
- 구조적 오류: 현대약품 + 안국약품이 동일 제약 테마로 겹쳤음. 이후 동일/고상관 테마 중복 금지.

### A 기존 모멘텀 기준 2회차: 2026-08-07 → 2026-08-10
- 시작자산: 590,560원
- 손익: -12,160원
- 수익률: -2.06%
- 종료자산: 578,400원

### B 가치+모멘텀 기준 2회차: 2026-08-07 → 2026-08-10
- 시작자산: 590,560원
- 손익: -8,740원
- 수익률: -1.48%
- 종료자산: 581,820원

### 3회차 완료: 2026-08-10 종가 → 2026-08-11 09:30

- A 씨이랩: 13,810원 × 8주 매수 → 16,050원 매도
  - 손익 +17,920원, 계좌수익률 +3.10%, 종료자산 596,320원
- B 아이크래프트: 7,100원 × 16주 매수 → 6,820원 매도
  - 손익 -4,480원, 계좌수익률 -0.77%, 종료자산 577,340원

### 4회차: 2026-08-11

- A/B 모두 `NO_TRADE`
- 매수금액 0원, 현금비중 100%
- 분석 완료가 15:30 이후였고 최종 조건을 통과한 종목이 없었음

### 2026-08-12 새 시작 상태

- 기존 AI 모의거래 이력과 정산자산은 유지한다.
- A 시작자산 596,320원, B 시작자산 577,340원
- 이후 사용자 실제거래는 사용자가 명시적으로 기록을 요청한 경우에만 별도 수집한다.

## 3. 최신 단기 추천 핵심 규칙

### 3.1 현재 데이터 우선
이전 기억이나 이전에 봤던 시세를 현재 데이터로 간주하지 않는다.
추천 전 가능한 범위에서 다음을 최신 확인한다.

- 현재가
- 등락률
- 시가/고가/저가
- 거래량
- 거래대금
- 최근 가격 흐름
- 외국인 수급
- 기관 수급
- 프로그램 매매
- 관련 뉴스/공시

누락된 값은 추정하거나 만들어내지 않는다.
반드시 `확인 사실 / 해석 또는 추정 / 확인 불가`를 구분한다.
핵심 현재 데이터가 검증되지 않으면 강한 추천을 하지 않는다.

### 3.2 매번 시장 전체에서 새로 찾기
- 이전 추천 종목을 출발점으로 쓰지 않는다.
- 과거 추천 이력은 가산점이 아니다.
- 예전에 추천한 종목도 당일 현재 데이터로 다시 독립적으로 통과한 경우에만 재선정한다.

### 3.3 단타는 모멘텀 우선
우선순위:
1. 거래대금
2. 투자자 수급
3. 종가 강도
4. 장 막판 가격 흐름
5. 거래량 증가
6. 재료 지속 가능성
7. 기술적 위치
8. PER/PBR 등 가치지표

PER/PBR은 후순위 필터다. 저평가라는 이유만으로 종목을 고르지 않는다.

### 3.4 선호 조건
- 반도체 제외
- 50,000원 미만 우선
- NXT 애프터마켓 거래 가능 종목은 최종 추천에서 필수 제외
- 충분한 유동성/거래대금
- 명확한 단기 모멘텀
- 설명 가능한 상승 재료

50,000원 기준은 절대 제외선이 아니라 우선순위다.

### 3.5 모멘텀 후보
- 거래대금 증가
- 거래량 증가
- 외국인/기관 매수 우위
- 프로그램 매매 양호
- 당일 고가 부근 유지
- 장 막판 매수세 강화
- 돌파 후 가격 유지
- 주요 이동평균 위에서 강세 유지
- 상승 재료가 소진되지 않음

단순히 당일 상승률이 크다는 이유만으로 추천하지 않는다.

### 3.6 반등 후보
하락 종목은 아래 근거가 있을 때만 반등 후보로 본다.
- 매도압력 약화
- 명확한 장중 저점 형성
- 저점 이후 거래량 증가
- 주요 지지선 회복
- 5분봉 20선 회복(데이터가 실제 확인될 때만)
- 외국인/기관 매수 전환
- 프로그램 매매 개선
- 장 막판 매수 강화

### 3.7 기술분석
일봉:
- 캔들
- 거래량
- 5일/20일/120일선
- 최근 지지/저항
- 당일 고가/저가 대비 위치

5분봉:
- 20기간 이동평균 위/아래
- 이동평균 방향
- 이탈 후 회복 여부
- 눌림 후 지지
- 장 막판 거래량 증가
- 장중 신고가
- 고점 이후 매물 소화 여부

단, 실제 5분봉 데이터가 확보되지 않으면 추정하지 않는다.

### 3.8 테마·상관관계 통제
최종 추천에서는 동일 또는 고상관 테마당 최대 1종목.
독립된 재료와 위험요인을 가진 종목으로 분산한다.
적합한 종목이 부족하면 종목 수를 억지로 채우지 말고 현금을 남긴다.

### 3.9 구조적 위험
확인 가능할 때 아래를 함께 본다.
- 신용/미수
- 공매도
- 프로그램 매매
- 기관 기계적 헤지
- ETF/레버리지 흐름
- 단기 차익실현 압력

### 3.10 뉴스/외부 위험
- 공시
- 실적
- 수주/계약
- 정부정책
- 업종 뉴스
- 원자재
- 환율
- 금리
- 해외증시
- 지정학
- 주말/휴일 리스크

뉴스가 이미 주가에 반영됐는지와 지속 가능성을 반드시 본다.

## 4. 최종 추천 규칙

- 최종 종목 수: **0~3개**
- `NO_TRADE` 허용 및 선호
- 동일 테마 최대 1종목
- 총 투자금 가정: **500,000~700,000원**
- 일일 목표수익: **10,000~20,000원**
- 일일 최대손실 목표: **약 10,000원**
- 확신이 낮으면 전액 투자하지 않고 현금을 남긴다.

최종 후보마다 반드시 제시:
- 추천 이유
- 현재 상승/반등 동력
- 지속 가능성
- 중요한 가격대
- 수급 특징
- 주요 위험
- 추천 무효화 조건
- 진입가
- 비중
- 투자금
- 수량
- 손절가
- 1차 익절가
- 2차 익절가

손실한도에 맞추려고 손절선을 비정상적으로 좁히지 않는다. 손절 논리가 불명확하면 `NO_TRADE`.

## 5. 실시간 데이터 사용 원칙

현재 웹 환경에서는 모든 장중 데이터를 초 단위로 안정적으로 얻는다고 가정하면 안 된다.

### 비교적 안정적으로 확인 가능한 것
- 뉴스/공시
- 투자주의/경고/단기과열 여부
- 재무/실적
- PER/PBR/ROE
- 최근 일봉
- 테마/업종 변수
- 전일 종가

### 시각 확인이 있을 때만 사용
- 현재가
- 당일 고가/저가
- 거래량
- 거래대금
- 등락률

### MTS/API 없이는 핵심 추천값으로 사용하지 말 것
- 정확한 15:25 현재가
- 실시간 5분봉 20선
- 호가잔량
- 체결강도
- 정확한 순간 외국인/기관 수급
- 초단위 프로그램 매매

웹 가격을 현재가라고 말할 때는 반드시 갱신 시각을 확인한다.
갱신 시각이 불명확하면 `가격: 웹/시각불명`으로 표시하고 진입가 산출에 쓰지 않는다.
사용자가 mPOP 등 MTS 값을 제공하면 그 값을 우선한다.

## 6. 일일 MD 작성 형식

매일 제목과 목차 순서를 동일하게 유지한다.

1. 테스트 기준
2. **전 거래 결과**
3. **종목별 성공/실패 원인**
4. 시장 후보 평가
5. 최종 추천
6. 다음 거래일 검증 시나리오
7. 결과 기록 항목
8. A/B 비교
9. 하루 총평
   - 잘된 점
   - 실패 원인
   - 다음 거래에 반영
   - 로직 수정 판단
10. 데이터 출처

### 후보 종목별 고정 하위 항목
- 당일 데이터
- 모멘텀 평가
- 가치·재무 평가
- 위험 요인
- 최종 판정

### 전 거래 결과 작성 원칙
전날 매수 → 다음 거래일 매도 결과를 반드시 앞부분에 기록한다.
종목별로 성공/실패 원인을 구체적으로 적는다.
외부 뉴스, 업종 변수, 유가/환율, 지정학, 주말 리스크 등 실제 결과에 영향을 준 요인은 별도 설명한다.
확인되지 않은 원인은 사실처럼 쓰지 않는다.

## 7. 사용자 실제거래 데이터 수집

사용자가 실제거래 기록을 명시적으로 요청한 경우에만 AI 모의거래와 섞지 않고 **사용자 실제거래**로 별도 기록한다.

매수 시 수집 항목:

- 종목명과 종목코드
- 매수일과 매수시각
- 매수가와 수량
- 총매수금액
- 수수료·세금(확인 가능한 경우)
- 사용자가 선택한 이유
- 당시 AI 추천 포함 여부

매도 시 수집 항목:

- 매도일과 매도시각
- 매도가와 수량
- 총매도금액
- 실현손익과 수익률
- 매도 이유

일부 정보가 없으면 추정하지 말고 `미제공`으로 표시한다. 사용자가 기록하지 않겠다고 한 거래는 파일에 흔적이나 추정값을 남기지 않는다. 사후 전달된 거래도 실제 체결값을 우선하며 AI가 제시했던 가격으로 대체하지 않는다.

## 8. 엑셀 작성 규칙

기존 시트 구조를 유지한다.

현재 시트:
1. `A_기존기준`
2. `B_새기준`
3. `A_일별요약`
4. `B_일별요약`
5. `A_B_비교`
6. `사용규칙`
7. `사용자_실제거래`

원칙:
- 기존 행/수식/서식을 함부로 삭제하지 않는다.
- 새 거래일은 다음 빈 행에 추가한다.
- 파생값은 가능하면 수식으로 계산한다.
- 순환참조 금지.
- `#REF!`, `#DIV/0!`, `#VALUE!`, `#N/A`, `#NAME?`가 없어야 한다.
- 빈 행에 불필요한 수식을 미리 깔지 않는다.
- 시트 참조 수식은 단순하게 유지한다.
- 사용자가 준 실제 매수가/매도가를 원천값으로 기록하고, 손익/수익률은 수식으로 계산한다.
- A/B의 시작자산은 각자의 전 거래 종료자산을 이어받는다.
- 이전 거래의 데이터는 새 기준 변경 때문에 소급 수정하지 않는다.

## 9. 기존 기록에서 반드시 기억할 실패 포인트

- 1회차에서 제약주 2개를 동시에 담아 동일 테마 중복 오류 발생.
- 2026-08-07 금요일 종가베팅은 주말 중동/유가 리스크가 다음 거래일에 영향을 줬을 가능성이 있음.
- 팬오션/대한항공처럼 운송·경기민감 성격이 겹치는 종목은 동시에 추천하지 않는다.
- 단기 전략에서 저평가 지표는 주력 선정 기준이 아니라 후순위 보조 필터로 사용한다.
- 장중 추천에서 단순 `상승률 + 거래대금`만 보고 추격하면 진입이 늦을 수 있으므로 **진입 위치/과열 여부**를 반드시 별도 평가한다.
- 이전 추천 종목을 반복적으로 다시 찾는 편향을 금지한다.

## 10. 응답 원칙

- 모르는 값은 만들지 않는다.
- 최신 데이터가 아니면 최신이라고 표현하지 않는다.
- 확인 필요하면 `확인이 필요합니다`라고 명시한다.
- 추정이면 `추정입니다`라고 표시한다.
- 조건이 부족하면 종목을 억지로 채우지 않는다.
- 사용자가 실시간 MTS 값을 주면 해당 값을 가장 높은 우선순위로 사용한다.
- 결론부터 제시하고, 실전 판단에 필요한 가격/비중/리스크를 우선한다.

**매일 거래할 필요는 없다. 증거가 충분하고 손익비가 유리하며 손실을 통제할 수 있을 때만 거래한다. 조건이 없으면 NO_TRADE.**
