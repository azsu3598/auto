# NVIDIA FY2027 Q2 연계 국내주 분석

## 결론

현재 매수 우선순위는 **하나마이크론(반도체 후공정)**, **대한전선(AI 데이터센터 전력망)** 순이다. HBM 장비 중 테크윙은 연관성이 더 직접적이지만 밸류에이션과 50,000원 저항 때문에 관찰 후보로 낮춘다.

## 데이터 및 NVIDIA 실적 검증

- 분석 시각: 2026-08-27 09:22 KST
- 국내 가격: 네이버증권 KRX 실시간 표기(지연 0분)
- 시장: 코스피 6,966.36(+2.32%), 코스닥 833.23(+0.77%)
- NVIDIA 공식 발표 확인: 매출 962억달러, 데이터센터 890억달러, Non-GAAP EPS 2.22달러, 다음 분기 매출 가이던스 1,080억달러±2%, 총마진 가이던스 74.0%±0.5%p
- NVIDIA는 SK하이닉스와 차세대 메모리 다년 협력을 공식 발표했다. 사용자가 제시한 FY2028 약 70% 성장 발언은 공식 실적 보도자료에서는 확인되지 않아 별도 어닝콜 원문 확인이 필요하다.
- NXT 종목 목록을 확인해 최종 후보에서 NXT 대상 제외

## 수혜 구조 판단

1. HBM·메모리: 가장 직접적이나 SK하이닉스·삼성전자는 가격 조건과 NXT 제외 규칙에 부합하지 않음
2. 후공정·검사 장비: HBM 증설의 2차 수혜. 실적과 실제 납품 전환 속도 확인 필요
3. 데이터센터 전력망: GPU 설치량 증가가 전력망 투자로 연결되는 중장기 수혜

## 최종 추천

### 1. 하나마이크론(067310)

- 09:21 확인가: 37,400원(+1.49%)
- 진입: **37,200~37,450원**, 37,200원 지지 유지 시
- 손절: 36,700원
- 1차/2차 목표: 37,850원 / 38,500원
- 배분: 모의자금 598,280원 기준 4주, 약 149,600원(25%)
- 근거: 반도체 패키징·테스트 업체, 2.5D 첨단 패키징 양산 계획, 최근 분기 실적 개선, 오늘 2분기 경영실적 IR, 거래대금 약 85억원
- 위험: HBM 직접 제조사가 아니며 2.5D 양산은 향후 계획이다. IR 내용에 따라 변동성이 커질 수 있음
- 무효화: 37,200원 지지 실패 또는 IR에서 성장 가정 훼손

### 2. 대한전선(001440)

- 09:22 확인가: 29,550원(+4.79%)
- 진입: **29,450~29,650원**, 29,400원 지지 확인 시
- 추격 금지: 29,900원 이상
- 손절: 29,000원
- 1차/2차 목표: 29,900원 / 30,500원
- 배분: 5주, 약 147,750원(25%)
- 근거: 거래대금 179억원, 전력기기 업종 동반 강세, 호주 AI 데이터센터용 330kV 전력망 프로젝트 수주로 수혜 연결이 실제 계약으로 확인됨
- 위험: 당일 이미 약 5% 상승했고 추정 PER이 높아 단기 차익실현 가능
- 무효화: 29,400원 지지 실패 또는 전력기기 업종 동반 약화

두 종목의 예상 손절 위험 합계는 약 5,550원이며, 약 50%는 현금으로 유지한다. 조건부 추천일 뿐 자동 모의매수는 아직 기록하지 않는다.

## 관찰·제외 후보

- 테크윙: HBM 검사 장비 연관성은 높지만 49,700원으로 50,000원 저항에 접근했고 PER 403배·PBR 8.68배로 과열 위험이 큼
- KBI메탈: 전력망 수혜 논리는 있으나 대한전선보다 변동성이 크고 직접 AIDC 계약 근거가 약함
- 에이팩트·엑시콘: 각각 -7%대·-1%대로 현재 매도 압력 변화가 확인되지 않음
- 시그네틱스·기가레인: 전일 또는 당일 급등 후 고점 이탈로 추격 제외
