## 현재 사용 파일

- `../reference/종가베팅_일일기록_현재본.md`: 오늘 분석, 최종 추천, 모의 매수와 다음 거래일 검증 기록
- `../reference/종가베팅_거래기록_현재본.xlsx`: A/B 모의거래 원장, 일별 요약, 비교 결과와 사용 규칙
- `../reference/종가베팅_다른세션_작성지침.md`: 다른 세션에서도 동일한 기준을 적용하기 위한 운영 지침
- `../AGENTS.md`: 종목 선별, 위험관리, 보고서와 거래기록 작성의 최상위 프로젝트 규칙

현재본은 매 거래일 갱신한다. 과거 데이터는 삭제하거나 현재 기준으로 소급 수정하지 않는다.

## 보존 파일

- `../reference/종가베팅_20260810_A_B_테스트기록.md`: 2026-08-10 일일 기록 원본

- `YYYY-MM-DD_HHMM_korean-stock-analysis.md`: 해당 시각의 시장 분석 스냅샷

시각별 분석 보고서는 이후 정보가 달라지더라도 원칙적으로 수정하지 않는다. 단순 오기나 데이터 출처 표기 오류만 바로잡는다.

## 기록 구분

- **AI 모의거래:** A 모멘텀형과 B 가치+모멘텀형으로 분리
- **사용자 실제거래:** 사용자가 기록을 명시적으로 요청하고 체결값을 제공한 경우에만 별도 시트에 추가
- **`NO_TRADE`:** 종목 없음, 매수금액 0원, 현금비중 100%로 명시

종가베팅은 15:25까지 선정하고 15:30 KRX 종가를 매수가로 사용한다. 15:30 이후 완료된 분석을 종가 매수로 소급 기록하지 않는다.
